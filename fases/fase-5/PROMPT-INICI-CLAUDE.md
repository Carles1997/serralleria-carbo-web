# Primer encàrrec per a Claude Code · Fase 5

Obre C:\Projects\Serralleria Carbó com a carpeta del projecte. Llegeix CLAUDE.md i aplica la skill serralleria-carbo-project. La Fase 4 ja està validada i el teu treball és iniciar la implementació amb Astro, sense redissenyar l'arquitectura ni els mockups.

Abans d'editar, comprova git status, l'absència o presència d'una aplicació Astro, les versions de Node i npm, i llegeix fases/fase-4/FASE4-traspas-desenvolupament.md, el sitemap de Fase 1, CONTEXT-serralleria-carbo.md, DESIGN.md i design/tokens.css. Quan un document antic discrepi de la validació de Fase 4, segueix el traspàs més recent i indica la discrepància. Preserva els canvis locals de les fases anteriors; no facis commit ni push sense una petició meva.

Primer objectiu: preparar una base Astro mínima i mantenible per a la Fase 5, amb Tailwind, Content Collections + Zod i la infraestructura i18n prevista. Integra Source Sans 3 local i els tokens aprovats, però no implementis encara totes les pàgines ni activis el formulari. Crea només els fitxers necessaris, fixa versions en un lockfile i defineix scripts útils de comprovació. Si cal triar una convenció d'URL o una dependència que afecti el sitemap, explica la decisió abans d'aplicar-la.

No inventis dades, projectes, fotos reals, certificacions ni textos legals. No utilitzis Impeccable per editar ni activis hooks. Pots consultar emil-design-eng com a criteri puntual; reserva review-animations per quan hi hagi moviment implementat. Taste Skill i altres skills de la proposta externa no estan autoritzades com a fonts d'arquitectura.

Verifica que la base arrenca i construeix, i que no has modificat els mockups aprovats. Acaba amb un resum dels fitxers creats, proves executades, riscos i el següent pas concret: una primera plantilla de referència abans de replicar-la a la resta de rutes.
